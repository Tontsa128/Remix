# Image attribution

Elovio's current visual-vocabulary starter set uses two unmodified photographs from Wikimedia Commons and four original illustrations authored for the learning objectives.

The photographs are displayed without modification. Attribution is shown in the vocabulary screen, with a link to each source page. The image files are served from Wikimedia Commons rather than copied into this repository. If a source image cannot be loaded, the screen reports that clearly and keeps the text exercise usable.

## Rules for future media

Before expanding the catalogue, each external image must have a verified source page, a licence that permits commercial reuse, and the required author/licence attribution. Original illustrations must be created for the learning objective and recorded in the catalogue as original Elovio artwork. Do not use unverified image URLs or assume that a search result grants reuse rights.
